ASMATH TECHNOLOGIES WEBSITE

Open index.html in a browser to preview the site. Keep the assets folder beside index.html; it contains the supplied brand logos.

The contact form prepares an email addressed to info@AsmathTechnologies.com and opens the visitor's default email app. It does not send form data to a server, so visitors need an email app configured to send the message.

The built-in chatbot responds to common questions about the listed services and contact options. It runs in the browser and does not use an AI service or send chat messages to a server. For a server-powered AI chatbot or direct form submissions, configure a backend and its credentials before deployment.

The site is static and has no build step or external assets. You can host it on any static web host. Before launch, confirm all service descriptions match what you can deliver.
